# 实验室开放时间

各实验室的开放时间如下，预约时段必须落在开放时间之内。

## 开放时间一览
- 人工智能基础实验室：周一至周五 08:00-21:00，周末 09:00-17:00
- 人工智能实验室：周一至周五 08:00-21:00，周末 09:00-17:00
- 软件工程实验室：周一至周五 08:00-21:00，周末 09:00-17:00
- 电子电路实验室：周一至周五 08:30-20:00，周末不开放
- 大学物理实验室：周一至周日 08:00-20:00
- 化学实验室：周一至周五 08:30-18:00，周末不开放
- 生物实验室：周一至周五 09:00-18:00，周末不开放
- 机器人实验室：周一至周日 09:00-21:00

## 注意事项
1. 开放时间内仍需先预约并等待审核通过，不能直接进入实验室。
2. 周末不开放的实验室，其预约日期只能选择工作日。
3. 预约的结束时间不能晚于实验室当日闭门时间，例如化学实验室最晚只能约到 18:00。
4. 节假日开放安排如有调整，以管理员公告为准。
